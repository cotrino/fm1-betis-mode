# FM1 Betis Mode

Unofficial Betis-themed firmware for **M-VAVE FM1**, built from the official
[FM1 Open V13 source + binary SDK](https://github.com/m-vave/fm1_open).
The hardware package and browser emulator use the same application sources.

- [Online emulator and firmware workbench](https://cotrino.github.io/fm1-betis-mode/)
- [Download flashable firmware](https://cotrino.github.io/fm1-betis-mode/FM1_BETIS_MODE.fwsc)
- [Matching source + SDK archive](https://cotrino.github.io/fm1-betis-mode/source.zip)
- [Firmware validation report](https://cotrino.github.io/fm1-betis-mode/firmware-report.json)
- [Run browser acceptance tests](https://cotrino.github.io/fm1-betis-mode/verify-emulator.html)

**Build-verified does not mean hardware-tested.** The package is generated by
the official packager with its boot/update resources, flash layout, build
identity and recovery image. No physical FM1 has been flashed or tested.
Back up projects and samples before installing. This is a community
modification, not an M-VAVE-endorsed release.

## Betis controls

The 240x240 RGB565 TFT starts at the **Manque Pierda** dashboard, with a green
theme, the supplied shield/Palmerin artwork, a tempo animation and MIDI-activity
jump/flash. Press **HOME+FX** to return to it from another page.

| Control | Dashboard action |
| --- | --- |
| SELECT | Select one of the eight tracks |
| Parameter knob 1: PASION | DX7 FM feedback (0-7), not available on non-FM tracks |
| Parameter knob 2: OLE REV | Selected track's reverb send |
| Parameter knob 3: DUENDE | Selected track's delay send |
| Parameter knob 4: BPM | Internal tempo, clamped to 60-180 |
| SCL | Toggle E Phrygian-dominant tuning / equal temperament |
| ARP | Toggle the selected track's official arpeggiator; hold for settings |
| PLAY | Play/stop the sequencer, including the crowd percussion on track 8 |
| SAVE | Open the official project save UI; no automatic persistent writes |
| HOME | Original eight-track overview |

The scale is **E F G# A B C D**, implemented with the official per-track
whole-cent tuning API. Original MIDI note identities remain independent, so
neighboring keys that quantize to the same pitch do not share note-off state.
Alt tuning is left unchanged. The default project enables track 1's arpeggiator
and includes an original synthesized 16-step 808 kick/clap/hat crowd rhythm.
Loading a saved project restores its own tuning, sounds, patterns and arp.

### Mas grada: guasa, goles y memoria betica

From the Betis studio, **FX** cycles through five shared hardware/browser views:
studio, **La Grada**, **Once 25/26**, **Memoria Betica**, and **Himno / Aprender**. HOME+FX returns to
the studio; HOME still opens the original overview.

- **La Grada:** K1 selects one of four original synthesized percussion patterns:
  Palmas del Heliopolis, Bombo de las 13 barras, Gol del Panda, Manque pierda.
  **EDIT explicitly replaces the first 16 steps of track 8**, which must still
  be an 808 instrument. Merely browsing never changes the project or source.
  Hidden steps beyond 16 are retained. PLAY starts/stops the normal sequencer;
  SAVE persists the pattern using the official project flow.
- **Matchday:** K2/K3 adjust Betis/opponent scores from 0 to 99; increasing the
  Betis score triggers a four-second goal message. Corrections are allowed.
  This is a manual toy scoreboard, not a live score service; it resets at boot.
  K4 retains the 60-180 BPM control. Thirteen green/white bars crown the display.
- **Once 25/26:** K1 browses a representative **2025/26 project selection**,
  not an official fixed starting XI. List numbers are not shirt numbers.
  Valles; Bellerin, Natan, Bartra, Ricardo Rodriguez; Amrabat, Fornals;
  Isco, Antony, Abde; Cucho Hernandez. Player descriptions are original
  fan-written flavor, not quotations or claims of official nicknames.
- **Memory:** 1907 roots, the 1935 Liga, Cups in 1977/2005/2022, thirteen bars,
  Palmerin, and Manque pierda.

The web-only hymn corner has separate **traditional / centenary** local-audio
players. Supply your own authorized files (up to 32 MiB each). Files are not
uploaded, stored, bundled, synchronized to transport, or copied into firmware.
No protected hymn lyrics, melodies, or recordings are distributed. The four
crowd patterns are original percussion, not versions of those hymns. For
device samples use the existing sample editor and its supported limits.

The **MIDI arranger/player** also accepts user-supplied type-0/1 PPQN MIDI
files (up to 2 MiB, two hours, 256 tracks). It flattens the tempo map to
millisecond timing, merges melodic channels to channel 1 (eight FM voices)
and retains percussion on channel 10. Sustain becomes note duration;
overlapping pitches keep independent ownership. Voice stealing is reported.
Original GM instruments, pitch bends, and other automation are deliberately
not retained: this is a new monotimbral FM arrangement, not an exact orchestral
render. The exported type-0 MIDI can be played into the hardware using an
external MIDI sequencer with track 1 FM/12-TET/ARP off and track 8 808.

Web playback uses the real AudioWorklet synth. It stops transport, temporarily
disables track 1's scale/ARP, and restores both at stop/end. Stop it before
editing or saving a project. Hiding the tab stops playback to prevent
background timer drift and stuck notes. Supplied originals and exported
arrangements remain local under ignored `himnos/`; they are not in Git, the
public source ZIP, public firmware, or deployed web page.

References checked for this implementation:
[Betisweb's 2025/26 squad listing](https://www.betisweb.com/web/list/plantilla-betis-25-26/)
for season membership (the XI itself is our selection), and the
[club's account of the 1935 championship](https://www.realbetisbalompie.es/noticias/actualidad/historia-el-ano-que-fuimos-campeones-24228).
The season is explicitly 2025/26, as requested, regardless of the current date.

### Integrated hymn and Aprender (private local build)

The supplied centenary MIDI can be compiled into a monophonic FM melody
that fits the physical 27-key keyboard. At each onset, the highest pitched
note in the selected melody track is used; out-of-range notes move by octaves,
preserving pitch class. This is a teaching reduction, **not** the earlier
eight-voice accompaniment arrangement. The melody, not recorded audio, lives
inside the native firmware and matching Wasm.

On **Himno / Aprender**, PLAY listens, EDIT starts the step-by-step lesson,
SCL stops, and HOME exits. The next note's physical key LED lights; a correct
new key press advances once, errors do not advance, and holding a key does not
auto-repeat. No rhythmic scoring is claimed. K1 seeks, REC repeats an
eight-note phrase. Track 1 must be FM; it uses a fixed octave, temporarily
disables its scale/ARP and restores those settings at stop/exit. Follow input
is the FM1 panel or on-screen keyboard; external MIDI input is not evaluated.
Do not load/save projects or change patches during a lesson.

```powershell
python .\tools\Compile-Hymn.py .\himnos\himno-centenario-del-betis.mid --track 1 --output .\vendor\fm1_open\app\betis_song_data.h
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -LocalHymn
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Verify.ps1 -LocalHymn
```

Private outputs are in ignored `local/docs/`, including firmware, a self-contained
workbench, and the **matching private source ZIP** with the generated melody header.
The SDK's embedded public source URL does not identify this private build; keep
its adjacent private archive with it and do not redistribute without permission.
Public builds refuse to run while the private header is in `app/`; move that
header outside `app/` before building for public distribution. No official
copyrighted photos or hymn data are committed.

### Original pixel artwork

The shield, mascot and eleven stylized fan portraits are original 32x40,
16-color illustrations rendered at 2x on the TFT. They use lossless run-length
compression to preserve the official flash/VM/user-storage reservation.
Isco, Antony, Cucho and the other selected players have separate portraits.
They are interpretive cartoons, not official photos or photorealistic likenesses.
Regenerate with `python .\tools\Generate-Betis-Art.py`; inspect the contact sheet
in [web/betis-sprites.svg](web/betis-sprites.svg).

## Preserved official features

The six-operator FM, 303, 808, PSG, pluck and sampler engines, eight tracks,
USB/BLE/TRS MIDI, Bluetooth and USB audio, project/sample storage, and recovery
workbench are retained. The browser uses the upstream portable synth kernels
and an AudioWorklet, not the earlier two-operator demo. Radio discovery,
board timing, actual Flash writes, analog output and battery behavior still
need device validation.

**Native sound-control adaptation:** the early project draft requested
standalone drive/chorus DSP. This release deliberately uses the official FM
feedback and reverb/delay sends rather than replacing the native audio engine
with an unverified demo. These dashboard controls do not pretend to be a
new saturation or chorus implementation.

## Reproduce the build (Windows x64)

Requires PowerShell 5.1+, Git, `curl.exe`, and `tar.exe`; no system-wide compiler
installation or administrator rights are needed:

```powershell
git clone https://github.com/cotrino/fm1-betis-mode.git
Set-Location fm1-betis-mode
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Verify.ps1
```

The bootstrap downloads and checksum-verifies **JieLi 2.5.2** and **WASI SDK
27** into `.tools/`. JieLi 2.5.3 does not match this SDK's compiler hashes.
Existing compatible installations can be reused with `FM1_PI32_TOOLCHAIN` and
`FM1_WASI_SDK`. The vendor SDK itself is not modified; its integrity checks,
linker/ABI/SRAM checks and source packager all run normally.

Outputs in `docs/`:

- `FM1_BETIS_MODE.fwsc`: flashable package.
- `index.html`: self-contained emulator, updater and stock V15 recovery UI.
- `simulator.wasm`: independently testable browser module.
- `source.zip`: exact corresponding sources, SDK and build/install scripts.
- reports, notices and `SHA256SUMS.txt`.

The upstream commit and changed vendor files are recorded in `upstream.json`.
The generated workbench adds branding/navigation to the upstream HTML;
the packaged firmware and Wasm payloads remain unchanged and are checked
against the downloadable files.

## Browser verification

Serve the repository locally:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Open `http://localhost:8080/docs/` for the workbench or
`http://localhost:8080/tests/verify-emulator.html` for executable acceptance
tests. Tests boot the real Wasm application and check tuning, TFT pixels, BPM
bounds, ARP, finite bounded FM audio, independent note release, silence after
release, project/tuning round-trips, and sequenced percussion.

Click the workbench's audio control before playing. Web MIDI requires a
compatible browser on HTTPS or localhost and explicit permission. Device
firmware updates are a separate explicit action in the workbench: none are
performed during builds or emulator tests. Keep the device powered throughout
an update; use the included original V15 recovery option if needed, following
the official recovery instructions.

GitHub Pages serves the committed `docs/` directory from `main`. The Windows
CI workflow rebuilds and verifies packages and uploads them as an artifact;
publishing a changed build requires committing its refreshed `docs/`.
